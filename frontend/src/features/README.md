# Frontend features

Add screens and feature-specific components here as each replacement task is implemented.
Keep the application entry in `app/`, reusable UI in `shared/ui/`, API transport in
`shared/api/`, and global tokens/styles in `shared/styles/`.

Use the backend domains as the starting boundaries: `auth`, `users`, `notes`,
`reviewers`, `quizzes`, `attempts`, and `flashcards`. New plan domains such as books,
sharing, workspaces, integrations, and offline support belong in separate features
when implemented. Do not add placeholder endpoints or imply those features work.
