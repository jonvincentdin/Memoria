## Minimum exercise

Create both issues and corresponding cards. For AUTH-01, create a branch with its real issue number and add a registration scaffold or a useful registration requirements clarification. Commit with an accurate message such as `docs(auth): clarify registration validation` if it is only documentation. Open a PR and include `Closes #<actual-number>` only when the issue's full acceptance criteria are fulfilled; use `Refs #<actual-number>` for partial scaffolding.

Have a different member review the change and record findings below. A scaffold PR can satisfy the traceability exercise without completing the whole feature. Leave the feature open until its implementation acceptance criteria pass.
