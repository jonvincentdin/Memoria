# Memoria

<!-- impeccable:product-schema 1 -->

## Platform
web

## Users and purpose
Students organize personal notes, manually prepare reviewers, take multiple-choice quizzes, and revisit saved scores. Existing scope is documented in docs/requirements.md.

## Stack and constraints
React JavaScript and Vite frontend; Spring Boot backend. The current task is the login and signup frontend. Authentication endpoints are not implemented; forms must never claim authentication succeeded or persist passwords.

## Brand commitments
The user selected the proposed green-and-paper direction after reviewing alternatives: forest green, warm white, charcoal, a book mark, serif headings, and readable sans-serif form text. Desktop uses a study preview beside the form; mobile prioritizes the form.

## Evidence
Requirements, team documentation, and runnable scaffolds exist. No user testimonials or adoption statistics have been supplied.
